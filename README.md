# CAT 2026 tracker and plan

A daily tick tracker, the full 50-day plan, and the PDF, in one folder.

Files
- index.html : the tracker (ticks, day %, week %, overall %, mock scores) and a "Plan and notes" tab
- CAT_2026_50_Day_Plan_Tracker.pdf : the same plan as a PDF with fillable tick boxes

Use it on your computer
1. Keep the folder together. Open index.html in Chrome, Edge, Firefox or Safari.
2. Use the same browser each time. Progress is saved in that browser.
3. Click "Export progress" now and then. It downloads cat2026-progress.json.
   Use "Import progress" to load it again on another device or browser.

Host it on GitHub Pages (free, public)
1. Create a GitHub account, then a new repository (for example "cat-2026"). Set it to Public.
2. In the repository choose Add file, then Upload files, and drag in index.html and the PDF. Commit the changes.
3. Go to Settings, then Pages. Under Build and deployment, set Source to "Deploy from a branch",
   pick the main branch and the root folder, and save.
4. After a few minutes (it can take up to 10) the site is at https://YOUR-USERNAME.github.io/cat-2026/

Notes
- Anyone with the link can see the site. It contains the plan, not your progress.
- Your progress is NOT stored on GitHub. It stays in each browser. Use Export progress, and if you want a
  history in git, commit cat2026-progress.json to the repository yourself.
- Phone and laptop do not sync with each other. Export on one, import on the other.
